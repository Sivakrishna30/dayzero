# DayZero [MVP]
## "Blinders On. Target Locked."

DayZero is a professional, distraction-free study companion designed specifically for TNPSC (Tamil Nadu Public Service Commission) aspirants. 

### 🐎 The Philosophy
The app is built on the **Horse with Blinders** metaphor. In the high-stakes world of competitive exams, chasing too many targets leads to catching none. DayZero forces a singular focus, helping you lock your eyes on one specific Combined Civil Service target to maximize your chances of success.

### ✨ Key Features
- **Target Locking**: Dedicated support for:
    - **Combined Civil Services – I (Group I)**
    - **Combined Civil Services – II (Group II / IIA)**
    - **Combined Civil Services – IV (Group IV)**
- **Real-time Countdowns**: Dynamic "Days to Go" calculations based on official 2026 exam dates.
- **Dual-Mode Syllabus**: 
    - **Reference View**: Clean, read-only syllabus list for pure information.
    - **Interactive Tracking**: Dedicated Progress Update page with checkbox-based topic management.
- **Strategic Intelligence**: Descriptive success factors (Vacancies, Difficulty Level) and historical numerical cutoff data for all communal categories.
- **Annual Planner**: Built-in 2026 examination schedule reference.
- **Privacy First**: Guest Mode using local `AsyncStorage` (Cloud sync planned for future release).

### 🛠 Tech Stack
- **Framework**: React Native / Expo
- **Storage**: AsyncStorage
- **Design**: Modern Minimalist (White Theme)

### 🚀 Getting Started
1. **Clone the repo**: 
   ```bash
   git clone https://github.com/Sivakrishna30/dayzero.git
   ```
2. **Install dependencies**: 
   ```bash
   npm install
   ```
3. **Run the app**: 
   ```bash
   npx expo start
   ```
